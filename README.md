# Fantasy Tavern Keeper (Android APK)

Hand-painted fantasy RPG kit demo wrapped as an installable Android app.

## Download
- **[FantasyTavern-debug.apk](./FantasyTavern-debug.apk)** (debug-signed, ~900 KB)

## Install
1. Download the APK to your Android phone
2. Enable **Install unknown apps** for your browser/file manager
3. Open the APK and install
4. Launch **Fantasy Tavern**

## App details
| Field | Value |
|------|------|
| Package | `com.fantasy.tavern` |
| Min Android | 7.0 (API 24) |
| Orientation | Landscape |
| Type | Offline WebView game (assets bundled) |

## How to play
- Tap inventory icons to select
- **Rest** — restore energy (fills the bar)
- **Sell** — sell selected item for gold
- **Craft** — spend energy for gold

Art style: hand-painted 2D fantasy RPG (props, icons, buttons, panel, progress bar).

> Debug APK is signed with the Android debug keystore — fine for sideloading / testing, not for Play Store.
